# Скульптор речи · macOS 0.3

Нативный личный тренер речи. Дизайн **Signal Studio** — тёмная аудиостудия, акцент лайма. Важная оговорка: это **исходный код**, а не протестированный `.app` на реальном Mac.

## Функции, реализованные в исходниках

- Ручная запись звука через микрофон Mac в `.m4a`, продолжает работать при свёрнутом окне.
- Импорт M4A / MP3 / WAV / CAF / AIFF.
- Прослушивание и локальная история, удаление записей.
- Распознавание русской речи с помощью **Apple Speech** (`SFSpeechRecognizer`). По умолчанию запрашивается **только локальное** распознавание; если оно недоступно — текстовая аналитика не выполняется, а пользователь получает объяснение. Опциональное распознавание серверами Apple включается отдельно.
- Базовый разбор: возможные слова-паразиты, число слов, ориентировочный темп, паузы на основании амплитуды, оценка интонационного диапазона по автокорреляции. Данные ориентировочные, не клинические. При наличии других говорящих показатели могут включать их речь.
- До трёх рекомендаций, упражнения, запись повторной попытки, статистика записей/паразитов/выполненных попыток.
- **Необязательный** ИИ-разбор: локальный сервер Ollama (не встроен в пакет, требует отдельной установки модели) или OpenAI API. Отправка транскрипта запускается только по кнопке; OpenAI API-ключ хранится в Keychain.

## Что пока не реализовано

- Встроенная в дистрибутив языковая модель с весами и LoRA-дообучение.
- Надёжная диаризация для очных разговоров.
- Захват онлайн-встреч (умышленно исключён из MVP).
- Подписанные автоматические обновления Sparkle (нужны подпись, нотарификация и настройки GitHub Releases).
- Профессиональная оценка дикции и "эмоций".

## Сборка через GitHub без Xcode на своём Mac

1. Создать приватный GitHub-репозиторий и положить файлы этого архива в корень репозитория.
2. GitHub Actions → **macOS application build** → **Run workflow** (или push в `main`).
3. Если сборка прошла, открыть artifacts и скачать `SpeechSculptor-macOS-development`.
4. Распаковать `.app` в `/Applications`. Первая неподписанная сборка может блокироваться Gatekeeper; для постоянной раздачи приложений потребуется Developer ID и нотарификация.
5. Проверить доступ к микрофону и распознаванию речи. Если `ru-RU` on-device недоступен, приложение это сообщит.

Важно: этот архив пока не является готовым проверенным установщиком. Сборку `.app` нужно выполнить на macOS runner. При неуспехе Actions сохраняет журналы.

## Сборка локально (для разработчика)

- macOS 14.2+, совместимый Xcode.
- `brew install xcodegen`, `xcodegen generate`, `xcodebuild -project SpeechSculptor.xcodeproj -scheme SpeechSculptor -configuration Debug build`.

## Приватность

- По умолчанию никаких аудиофайлов и расшифровок никому не отправляется.
- Отдельная опция Apple Speech cloud разрешает облачную расшифровку; пользователь должен явно включить.
- Дополнительная LLM вызывается отдельно. Ollama работает через `http://127.0.0.1:11434`, OpenAI — через HTTPS. Отправляется расшифровка (до 9 тыс. символов) и измерения, без звукового файла.
- История хранится в `~/Library/Application Support/SpeechSculptor/`.
- Перед записью других людей требуется уведомление/согласие в зависимости от применимого закона.

## Критерии качества

Правила изоляции длинных слов-паразитов (без двойного счёта); при недостаточной достоверности интонации вместо оценки показывается "—". Отчёты не претендуют на абсолютное определение того, что "хорошая речь".
