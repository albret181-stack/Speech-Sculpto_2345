# Скульптор речи — продуктовые требования

**Пользователь:** человек, который хочет развивать собственную русскую речь с помощью живых и тренировочных записей.
**Главный сценарий:** записать → увидеть измеримые особенности → получить 1–3 конкретные подсказки → произнести заново → сравнить в истории.
**Нет:** онлайн-встреч и постоянной фоновой записи без явного старта.
**Метрики:** записи, потенциальные слова-паразиты (количество и на 100 слов), завершённые уроки (тренировочные записи с результатом), темп, ориентировочные паузы, вариативность F0 при наличии достаточного сигнала.
**ИИ:** правила и акустика локально; дополнительные провайдеры только по выбору пользователя. Подключаемые Ollama и OpenAI не эквивалентны встроенным весам LLM.
**Дизайн:** Signal Studio, крупные заголовки, графит, холодный зелёно-лаймовый акцент, никакого повторения интерфейса рабочего BI-приложения. Референс Impeccable: https://github.com/pbakaus/impeccable
**Конфиденциальность:** по умолчанию запись остаётся локально; отдельно согласовать передачу любой расшифровки внешнему поставщику.
**Цель MVP:** работающие ручная запись, импорт, расшифровка на совместимом Mac и базовый объяснимый разбор.
