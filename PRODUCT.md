# Скульптор речи — концепция первой версии

Цель: персональный тренер речи для macOS, ориентированный на запись очных разговоров через микрофон, импорт аудио и развитие навыков с помощью аналитики.

## Функциональность MVP
1. Запись микрофона Mac, остановка и сохранение M4A.
2. Импорт локального M4A/MP3/WAV.
3. Расшифровка на русском языке; если on-device Apple Speech недоступен, честно сообщаем об ограничении.
4. Измеряемые показатели: слова-паразиты / 100 слов, темп речи, ориентировочное количество пауз и разброс высоты голоса.
5. Три приоритетных замечания с объяснением, упражнение и запись попытки.
6. Локальная история и общие счётчики: записи, потенциальные слова-паразиты, упражнения.
7. Необязательная отправка транскрипта в Ollama либо OpenAI по явному действию пользователя.
8. Дизайн Signal Studio; обязательный дизайн-референс: https://github.com/pbakaus/impeccable

## Не реализовано в MVP
Онлайн-встречи, надёжное разделение говорящих, встроенные веса LLM, LoRA-дообучение, подписанные автообновления Sparkle.

## Принципы
Никаких выдуманных оценок и диагнозов. При недостатке данных показываем ограничения. Звук и записи по умолчанию остаются локально. Для записи других людей необходимо учитывать согласие.

## Сборка
GitHub Actions собирает unsigned development .app после появления полного исходного проекта. Для безопасной публичной раздачи нужны Developer ID, подпись и нотарификация.
