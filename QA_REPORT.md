# QA — проверка потенциальных слов-паразитов на синтетических текстах

Дата: 2026-10-26. Версия исходного приложения: v0.9.0.

## Что сделано
50 коротких синтетических русских фраз (не аудиозаписи), включая разговорные заполнители, обычные значения слов и смешанные конструкции. Разметка подготовлена авторами теста, независимо экспертами не проверена. Скрипт сравнивает количество срабатываний по каждой фразе и вычисляет precision, recall, F1.

## Результат CI
По журналу GitHub Actions run 40278380817:
- TP: 38
- FP: 0
- FN: 0
- Precision: 1.0000
- Recall: 1.0000
- F1: 1.0000

**Это оценка на небольшом, искусственном, заранее известном наборе; она не измеряет качество на живых разговорах и не доказывает эффективность модели.** Метрики могут быть завышены из-за простоты примеров и совпадения разметки с эвристиками.

## Ограничения и следующий шаг
1. Создать независимый корпус с реальными голосовыми записями, полученными с согласия участников, с ручной расшифровкой и разметкой слов-паразитов по временным диапазонам.
2. Разметку выполнить минимум двумя проходами и фиксировать спорные случаи.
3. Отдельно измерить WER распознавания и precision/recall/F1 классификации при исходном эталонном тексте и при распознанном тексте.
4. Добавить длинные высказывания, профессиональную лексику, разные темпы, паузы и шум.
5. Проверять производительность и разрешения на настоящем Mac; синтетический текстовый тест этого не делает.
6. Не выпускать приложение на основании только этого теста; блокировать выпуск при регрессиях и при потере исходного файла.

Данные теста: `Tests/fixtures/ru_fillers_50.json`. Запуск: `swiftc -o /tmp/sculptor-benchmark Sculptor/Models/AnalysisCore.swift Sculptor/Models/SpeechContext.swift Tests/FillerBenchmark.swift && /tmp/sculptor-benchmark`.
